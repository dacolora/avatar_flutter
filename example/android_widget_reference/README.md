# Archivos de referencia del widget Android

Esta carpeta **no** es la plataforma Android del proyecto — `example/`
todavía no tiene una (ver README principal, sección "Widget de pantalla de
inicio"). Son los archivos que hay que copiar **encima** del árbol que
genera `flutter create --platforms=android .`, ajustando el paquete al
`applicationId` real.

Ver el paso a paso completo en el `README.md` de la raíz del repo.
